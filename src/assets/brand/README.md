# Plynt — Spark P

사용자가 선택한 **01 Spark P / 스파크 P** 방향을 다듬은 앱 아이콘입니다. 보라색 바탕과 흰색의 각진 P를 사용합니다. 다른 AI 서비스의 로고를 그대로 복제하지 않았습니다.

- `spark-p-source.png`: 선택 시안을 바탕으로 이미지 생성 도구로 정리한 원본.
- `icon.png`, `favicon.png`: 데스크톱 UI용 128px / 32px.
- `../../../build/icon.png`, `icon.ico`: 설치 파일·운영체제용 1024px / 다중 해상도 ICO.
- `../../../mobile/android/res/drawable-nodpi/plynt_icon.png`: Android 런처용.

서비스 식별용 타사 아이콘은 별도 `../services/sources.json`에 출처를 기록합니다. 이 문서는 상표 등록이나 독점권 확인을 의미하지 않습니다.
