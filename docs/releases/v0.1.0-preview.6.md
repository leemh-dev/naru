# Plynt 0.1.0-preview.6 · Sidebar & tablet multiview

작업 관리 메뉴를 플린트 아이콘의 사이드바로 모으고, 저장한 워크스페이스 이름 변경과 Android 태블릿 멀티뷰를 추가했습니다.

- **사이드바:** 탭 맨 앞 플린트 아이콘에서 워크스페이스·보관 글·개인정보와 로그인·진단에 접근합니다. 탭 끝의 전역 `…` 버튼을 대체합니다.
- **이름 변경:** 현재 열지 않은 워크스페이스도 목록에서 바로 수정합니다. 기존 ID·탭·내용과 현재 작업을 보존합니다.
- **Android 태블릿:** 최소 화면 폭 600dp 이상이면 최대 4개 패널, 2×2 또는 좌우 열 배치. 제목을 길게 눌러 다른 패널에 끌면 위치가 바뀝니다. 나머지 탭은 전체 화면으로 열립니다. 휴대폰은 단일 화면을 유지합니다.
- **Plynt 이름 통일:** 저장소 주소는 `leemh-dev/plynt`, Java 소스 네임스페이스도 Plynt로 변경했습니다. 기존 앱 ID·런처 별칭·서명·데이터 경로는 업데이트 호환성을 위해 유지합니다.
- **소개 페이지:** 저장소의 `site/`에 소개·사용법·다운로드·개인정보 안내를 제공합니다. GitHub Pages 배포 상태는 README를 확인하세요.

## 설치·업데이트

**Assets**에서 운영체제에 맞는 설치 파일을 받으세요. `Source code.zip`은 설치 파일이 아닙니다. 최종 `SHA256SUMS.txt`와 실제 첨부 파일을 확인하세요.

| 환경 | 파일 |
|---|---|
| Windows x64 | `plynt-0.1.0-preview.6-win-x64.exe` / `.zip` |
| Mac Apple Silicon | `plynt-0.1.0-preview.6-mac-arm64.dmg` / `.zip` |
| Mac Intel | `plynt-0.1.0-preview.6-mac-x64.dmg` / `.zip` |
| Linux x64 | `plynt-0.1.0-preview.6-linux-x86_64.AppImage` |
| Debian·Ubuntu | `plynt-0.1.0-preview.6-linux-amd64.deb` |
| Android 휴대폰·태블릿 | `plynt-0.1.0-preview.6-android-test.apk` |

Android preview.5의 **공개 릴리스 APK와 같은 앱 ID·보관 키**로 서명합니다. preview.5는 기존 앱을 삭제하지 않고 업데이트하는 대상입니다. 이전 preview.4 또는 다른 키로 만든 개발 APK는 서명이 다를 수 있습니다. 삭제하면 로컬 작업과 로그인이 사라지므로 서명 불일치 시 임의로 삭제하지 마세요. CI 임시 키 APK는 공개 업데이트에 사용하지 않습니다. 공개 APK와 최종 체크섬은 서명 확인 후 별도로 첨부합니다.

데스크톱은 공인 코드 서명·Apple 공증 전 프리뷰이며 Android는 디버그 서명 호환성 시험판입니다. iPhone·iPad 앱은 없습니다.

## 검증 범위

Windows·macOS·Linux의 네이티브 Electron, Android 15 에뮬레이터의 휴대폰·태블릿 구성을 검사합니다. 릴리스 생성은 데스크톱·Android 검사가 모두 통과해야 합니다. [항목별 결과와 화면](https://github.com/leemh-dev/plynt/blob/main/docs/preview.6-validation.md)을 참고하세요.

검사는 개인정보 없는 합성 페이지와 합성 쿠키를 사용합니다. 실제 서비스 로그인 후 ChatGPT → Suno·Canva 입력은 미검증입니다. 탭 URL·배치는 저장하지만 사이트 내부 초안·스크롤·편집 상태를 앱 재실행 후 복원하는 것은 보장하지 않습니다. 이미지·음악·파일 전달, 클라우드 동기화, Android 패널 크기 비율 조절은 지원하지 않습니다. 전송·생성·외부 게시를 자동 실행하지 않습니다.

## English

Plynt now has a leading brand button and sidebar, in-place renaming of saved workspaces, and Android tablet multiview. Tablets with smallest screen width ≥600dp can show two to four panels in a grid or side-by-side columns, swap them by dragging their headers, and open other tabs full-screen. Phones remain single-panel. Saved workspace renaming does not switch or reload the current work.

The repository and Java source namespace use Plynt. Existing application identifiers, launcher alias, profile paths and the retained Android signing key remain compatible. Public preview.5 APK users should update without uninstalling. Other signing identities may be incompatible. Check the attached installers and SHA256SUMS; CI test APKs are excluded.

Tests use native app runtimes with synthetic pages and cookies. Actual authenticated AI workflows remain unverified. No automatic sending/generation, cloud sync, media transfer or iOS app. Desktop packages remain unsigned/not notarized; Android remains a debug preview. The `site/` directory contains the introduction and privacy pages; deployment status is documented in the README.
