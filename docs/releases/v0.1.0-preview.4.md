# Plynt(플린트) 0.1.0-preview.4

`+` 메뉴에서 **47개 AI 서비스를 8개 분류로 찾아 여는 기능**을 추가했습니다. 한글·영문 검색과 웹 주소 직접 입력을 지원합니다.

## 바뀐 점

- 챗·검색: ChatGPT, Claude, Gemini, Perplexity 등.
- 음악: Suno, Udio, AIVA, SOUNDRAW 등.
- 이미지: Midjourney, Adobe Firefly, Leonardo.Ai, Ideogram 등.
- 동영상: Runway, Kling AI, Luma, Pika, Google Flow 등.
- 디자인·발표: Canva, Figma, Gamma, Adobe Express.
- 개발: Codex Cloud, GitHub Copilot, Google AI Studio, Replit 등.
- 문서·리서치: Gemini Notebook(기존 NotebookLM), Elicit, Consensus, Notion.
- 음성·더빙: ElevenLabs, Murf, Speechify.

여러 용도를 가진 서비스는 관련 분류에도 표시합니다. 이전 제품명으로 검색할 수 있으며, 목록에 없는 사이트나 비공개 대화는 웹 주소로 직접 엽니다. 데스크톱과 Android가 공통 목록을 사용합니다. 최대 30개 탭, 최대 4개 멀티뷰, 글 전달 시 대상 탭 활성화는 유지합니다.

## 다운로드

아래 운영체제와 CPU에 맞는 파일을 **Assets**에서 선택하세요. `Source code.zip`은 설치 파일이 아닙니다.

| 환경 | 파일 |
|---|---|
| Windows x64 설치 | `plynt-0.1.0-preview.4-win-x64.exe` |
| Windows x64 무설치 | `plynt-0.1.0-preview.4-win-x64.zip` |
| macOS Apple Silicon | `plynt-0.1.0-preview.4-mac-arm64.dmg` 또는 `.zip` |
| macOS Intel | `plynt-0.1.0-preview.4-mac-x64.dmg` 또는 `.zip` |
| Linux x64 AppImage | `plynt-0.1.0-preview.4-linux-x86_64.AppImage` |
| Debian·Ubuntu x64 | `plynt-0.1.0-preview.4-linux-amd64.deb` |
| Android 호환성 시험 | `plynt-0.1.0-preview.4-android-test.apk` |

`SHA256SUMS.txt`에서 파일별 SHA-256 체크섬을 확인할 수 있습니다. 기존 앱 ID와 데이터 경로는 유지합니다. Android 버전 코드는 4이며 시험 APK는 디버그 서명입니다. CI 빌드마다 키가 달라질 수 있어 기존 APK와 키가 다르면 바로 업데이트할 수 없습니다. 앱 삭제 시 로컬 데이터가 사라질 수 있습니다.

## 검증 범위

Linux 합성 화면 GUI 30개, 재시작 6개, 새 바로가기 14개 검사와 단위 검사를 통과했습니다. Android는 APK 빌드와 공통 목록 포함 여부를 확인했습니다. 설치 파일은 Windows·macOS·Linux·Android CI 빌드가 모두 성공한 뒤 게시합니다.

**바로가기 추가는 서비스별 로그인·생성·입력 전달 호환성 검증이 아닙니다.** 새 Android 메뉴의 실제 조작, Android 로그인 완료·길게 누르기 전달, Windows·macOS 실제 실행, Suno·Canva 로그인 후 전달은 미검증입니다. 데스크톱은 코드 서명·Apple 공증 전 프리뷰이며 Android는 별도 호환성 시험 앱입니다. iOS 설치 파일은 없습니다.

진단은 로컬에만 저장하고 사용자가 직접 내보냅니다. 검색어·비공개 URL·본문은 수집하지 않습니다. 메시지 전송·유료 생성·외부 게시를 자동으로 실행하지 않습니다.

## English

The `+` menu now includes **47 AI services across eight categories**: chat/search, music, images, video, design/presentations, development, documents/research, and voice/dubbing. Search Korean or English names, including former product names. Multi-purpose services appear in relevant categories; custom URLs remain available. Desktop and Android share the catalog.

Choose an installer from **Assets** using the table above. Checksums are in `SHA256SUMS.txt`. Existing app identifiers and desktop data paths are retained. Android version code is 4; debug signing keys may differ across CI builds, preventing an in-place update. Uninstalling an older APK can delete local data.

Unit checks and 50 Linux synthetic-page GUI/restart checks passed. Android APK compilation and bundled catalog contents were checked. Publication requires all platform build jobs to succeed. **Catalog inclusion does not establish authenticated service compatibility.** Android menu interaction, completed Android sign-in and long-press transfer, Windows/macOS runtime, and authenticated Suno/Canva transfers remain unverified. Desktop builds are unsigned/not notarized; Android is a compatibility preview. There is no iOS build.

Diagnostics remain local until manually exported and exclude search queries, private URLs, and prompt text. The app does not automatically send messages, consume generation credits, or publish content.
