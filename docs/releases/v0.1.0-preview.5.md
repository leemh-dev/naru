# Plynt 0.1.0-preview.5 · Spark P

Android와 데스크톱의 글 전달·워크스페이스·서비스 선택을 개선하고 스파크 P 아이콘을 적용했습니다.

- 입력칸을 등록하지 않은 탭도 전달 목록에 나타납니다. 대상 선택 → 빈 입력칸 터치 → **여기에 넣기**. 실패한 글을 유지하고 기존 초안을 보호합니다.
- 서비스의 복사 버튼으로 가져온 글을 미리 보고 전달할 수 있습니다. 최근 목적지·보관 글을 재사용하고, ChatGPT 답변 가져오기는 실험 기능으로 제공합니다.
- 워크스페이스 자동 저장·이름·저장 상태·다른 이름으로 저장·새 빈 작업·전환·재실행 복원을 추가했습니다.
- 가로 스크롤 다중 분류, `All` 기본, 47개 AI 아이콘·약자, 맨 위 Google 브라우저 바로가기를 제공합니다.
- 정상 로그인 쿠키·웹 저장소를 유지하며, 로그인 데이터 삭제는 별도 확인 후 수행합니다. 비밀번호 저장이나 인증 우회는 하지 않습니다.
- 탭 최대 30개, 데스크톱 멀티뷰 최대 4개는 유지합니다. iOS 앱은 없습니다.

## 설치

**Assets**에서 운영체제와 CPU에 맞는 파일을 선택하세요. `Source code.zip`은 설치 파일이 아닙니다. 실제 첨부 파일과 `SHA256SUMS.txt`를 확인하세요.

| 환경 | 파일 |
|---|---|
| Windows x64 | `plynt-0.1.0-preview.5-win-x64.exe` / `.zip` |
| Mac Apple Silicon | `plynt-0.1.0-preview.5-mac-arm64.dmg` / `.zip` |
| Mac Intel | `plynt-0.1.0-preview.5-mac-x64.dmg` / `.zip` |
| Linux x64 | `plynt-0.1.0-preview.5-linux-x86_64.AppImage` |
| Debian·Ubuntu | `plynt-0.1.0-preview.5-linux-amd64.deb` |
| Android 시험 앱 | `plynt-0.1.0-preview.5-android-test.apk` |

**기존 공개 preview.4 Android APK와 서명이 달라 덮어 설치할 수 없습니다.** 앱 삭제는 로컬 작업·보관 글·로그인을 지웁니다. 필요한 URL과 자료를 먼저 별도로 보관하세요. preview.5부터 공개 APK는 보관된 키로 서명하고, CI 임시 서명 APK는 공개 릴리스에서 제외합니다. APK와 최종 체크섬은 서명 확인 후 별도 첨부합니다.

데스크톱은 공인 코드 서명·Apple 공증 전 프리뷰이며 Android는 디버그 서명 호환성 시험용입니다.

## 검증과 한계

Windows·macOS·Linux에서 실제 Electron을 실행해 새 기능 22개와 재시작 3개 검사를 수행합니다. Linux의 기존 배치·탭·선택·분류 검사 50개도 통과했습니다. Android는 실제 API 35 에뮬레이터의 네이티브 메뉴와 합성 WebView로 검사합니다. 릴리스는 데스크톱·Android CI 검사를 모두 통과한 뒤 생성합니다.

**합성 화면·쿠키 검사가 실제 서비스 로그인 성공을 의미하지 않습니다.** ChatGPT → Suno·Canva 로그인 후 입력과 실제 ChatGPT 답변 추출은 미검증입니다. 입력 중인 글·스크롤·편집 상태 복원, 이미지·음악·파일 전달, 클라우드 동기화는 지원하지 않습니다. 전송·유료 생성·외부 게시를 자동으로 실행하지 않습니다.

[검증 기록과 화면](https://github.com/leemh-dev/plynt/blob/main/docs/preview.5-validation.md)

## English

Spark P branding, unregistered destination tabs, copy-button-based text handoff with preview/recent targets, named local workspaces and horizontal multi-select service categories are now included on desktop and Android. Google is pinned above the icon-based catalog. Normal browser-engine sessions persist; passwords are not collected.

Choose the appropriate installer from **Assets** and verify `SHA256SUMS.txt`. **The public preview.4 Android APK has a different signing certificate and cannot update in place.** Uninstalling removes local work and sessions; preserve needed material first. From preview.5, published APKs use a retained key; temporary CI APKs are excluded. The verified APK and final checksum file are attached separately.

Native Electron checks run on Windows, macOS and Linux, with separate Android 15 native/WebView tests. These use synthetic pages and cookies, not authenticated accounts. Actual ChatGPT → Suno/Canva flows and the experimental ChatGPT answer extractor remain unverified on signed-in services. No automatic sending, generation or publication occurs. Desktop installers are unsigned/not notarized; Android is a debug compatibility preview. There is no iOS app, file transfer or cloud synchronization.
