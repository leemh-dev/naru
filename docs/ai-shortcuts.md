# AI 서비스 바로가기

`+ → 작업 추가`에서 8개 분류와 한글·영문 검색으로 **47개 서비스**를 찾습니다. 여러 용도를 가진 서비스는 관련 분류에도 나타나며, 전체 목록에서는 한 번씩 표시합니다. 이름으로 검색하면 전체 분류를 검색하고, 분류 버튼으로 결과를 좁힐 수 있습니다. 목록에 없는 사이트나 기존 비공개 대화는 웹 주소로 직접 엽니다.

데스크톱과 Android는 같은 `src/services.json` 목록을 사용합니다. 서비스 추가·수정은 이 파일의 이름·주소·검색어·분류를 편집합니다. 현재 목록에 있는 기본 ID를 바꾸면 기존 탭의 서비스 표시가 달라질 수 있으므로 ID는 유지합니다. 진단은 이 정적 목록의 ID만 허용하며, 검색어·웹 주소·페이지 내용은 기록하지 않습니다.

## 주소와 제품 설명 확인

확인일: **2026-11-18**. 아래 공식 사이트와 공식 사이트가 연결한 웹 진입점을 참고했습니다. 목록은 대표적인 서비스를 폭넓게 모은 것이며, 시장 점유율 순위나 모든 AI 서비스의 목록은 아닙니다.

**바로가기 등록은 로그인·생성·입력 전달의 호환성 검증이 아닙니다.** 일부 공식 페이지는 로그인 화면, JavaScript 전용 화면, 자동 수집 차단으로 본문을 읽지 못했습니다. Grok·DeepSeek는 운영사의 공식 사이트가 연결하는 주소를 확인했습니다. 요금제·지역·내장 브라우저 제한은 서비스에 따라 다릅니다. 실제 서비스에 로그인하거나 메시지 전송·유료 생성은 수행하지 않았습니다.

- Sora는 [OpenAI의 종료 안내](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation)에 따라 제외했습니다.
- [Gemini Notebook](https://notebook.google.com/)은 옛 이름인 NotebookLM·노트북LM으로도 검색됩니다.
- [Mistral Vibe](https://mistral.ai/products/vibe/)는 옛 이름 Le Chat·르샤로도 검색됩니다.
- Google Flow·Kling·Luma 등은 공식 페이지에서 확인한 현재 웹 진입점을 사용합니다.
- Codex Cloud 바로가기는 웹 작업 화면입니다. 설치형 Codex나 원격 데스크톱 전체 기능을 의미하지 않습니다.
