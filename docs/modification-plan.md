## 이름 변경 호환성

저장소 ID `1461224592`가 `leemh-dev/plynt`로 바뀐 것을 확인했습니다. 예전에 관리 API가 403을 반환한 기록은 과거 결과이며, 현재 저장소 이름 변경은 완료됐습니다.

Android Java 코드는 `dev.plynt.mobile.preview`로 옮겼습니다. **앱 ID와 기존 런처 별칭 `dev.naru.mobile.preview`만 유지**합니다. 이 값까지 바꾸면 기존 설치의 업데이트와 작업·로그인 데이터 접근이 끊깁니다. 보관된 서명 키와 이전 환경 변수의 호환 경로도 유지합니다. 과거 설치 파일명·검증 원본의 Naru 표기는 당시 사실을 보존합니다. 데스크톱 앱 ID와 사용자 데이터 경로도 유지합니다.

## 저장과 이름 변경

- 저장 목록의 각 작업에 이름 변경 버튼을 제공합니다. 현재 열지 않은 작업도 전환 없이 수정합니다.
- 이름은 공백 제거 후 1~60자입니다. 취소하면 이름과 저장 내용이 바뀌지 않습니다.
- ID·탭·URL·배치·보관 글을 유지합니다. 이름 변경을 위해 웹 화면을 다시 생성하지 않습니다.
- 로컬 저장이 실패하면 이름 변경 성공으로 처리하지 않습니다.

## 사이드바와 멀티뷰

- 플린트 아이콘은 탭 가로 스크롤 영역 밖에 고정됩니다.
- 데스크톱은 사이드바를 위한 화면 폭을 확보하고, Android는 WebView 위의 네이티브 서랍을 엽니다.
- 태블릿은 `▦`에서 2~4개 탭과 배치를 선택합니다. 3개는 위 2개·아래 1개로 자동 배치합니다. 열 배치는 항상 **좌측에서 우측으로**입니다.
- 패널 제목을 길게 누른 뒤 다른 패널로 끌면 두 위치를 교환합니다. 크기 비율을 자유롭게 조절하는 기능은 Android에 아직 없습니다.
- 다른 탭의 웹 화면을 터치하면 해당 탭이 활성화됩니다. 구성 밖 탭은 단독 화면, 구성 안 탭은 멀티뷰로 돌아옵니다.
- Android 태블릿과 데스크톱의 배치는 각 기기에서 저장합니다. iPad용 앱은 아직 없습니다.

## 소개 페이지 배포

목표 주소: `https://leemh-dev.github.io/plynt/`. 저장소 `Settings → Pages → Source: GitHub Actions` 설정 후 [소개 페이지 워크플로](../.github/workflows/pages.yml)를 실행합니다. 현재 연결의 최초 Pages 생성 요청은 `403 Resource not accessible by integration`으로 거절됐으며, 사이트가 공개됐다는 뜻은 아닙니다. 활성화 후 배포 결과를 별도로 기록합니다.
