## 저장소 이름 변경 진행 상태

2026-11-19에 GitHub 저장소 ID `1461224592`의 실제 이름이 `leemh-dev/naru`임을 확인하고 `name=plynt`로 변경을 요청했습니다. GitHub의 응답은 **HTTP 403 · Resource not accessible by integration**이었습니다. 현재 연결에는 이 관리 작업을 수행할 권한이 없으며, 이름 변경은 완료되지 않았습니다.

저장소 소유자는 [Settings → General](https://github.com/leemh-dev/naru/settings)의 **Repository name**에서 `plynt`를 입력하고 **Rename**을 실행할 수 있습니다. 비밀번호나 토큰을 전달할 필요는 없습니다.

변경 후에는 동일 저장소 ID의 새 주소를 먼저 확인하고 `git remote`, README의 현재 다운로드·문의·클론 링크, `package.json`의 저장소 메타데이터를 맞춥니다. 현재 동작하는 링크는 실제 변경 전까지 유지합니다. 앱 ID·사용자 데이터 경로·서명 키와 과거 검증 증거는 이 주소 변경 작업의 변경 대상이 아닙니다.
