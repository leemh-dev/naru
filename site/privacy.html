이 문서는 현재 공개 프리뷰의 저장·전달 동작을 설명합니다. 서비스별 웹사이트의 개인정보 처리와는 구분됩니다.

앱이 기기에 보관하는 정보

  • 워크스페이스 이름, 탭 URL·별칭·순서, 활성 탭과 멀티뷰 배치
  • 사용자가 명시적으로 보관한 글, 최근 전달 대상
  • 정상 로그인 후 웹 엔진이 관리하는 쿠키와 웹 저장소

자체 계정이나 클라우드 동기화 서버는 없습니다. 비밀번호를 별도로 수집하거나 다른 브라우저의 쿠키를 가져오지 않습니다. 여러 탭과 워크스페이스는 같은 기기의 서비스 세션을 공유합니다.

글을 다른 탭으로 보낼 때

선택한 글이나 사용자가 가져오기를 누른 클립보드의 글을 전달 후보로 사용합니다. ChatGPT 답변 가져오기 시험 기능은 사용자가 선택했을 때 현재 페이지에서 불러온 답변을 읽습니다. 대상 입력칸에 넣은 내용은 해당 서비스 웹페이지에서 접근할 수 있으므로 그 서비스의 개인정보 정책도 확인해 주세요. Plynt는 전송·생성 버튼을 자동으로 누르지 않습니다.

진단 정보

기본 진단에는 앱·운영체제·웹 엔진 버전과 허용된 동작·결과·오류 코드, 글자 수 등이 포함됩니다. 대화 원문, URL, 별칭, 비밀번호, 쿠키·토큰, 페이지 콘솔, 원본 오류 스택, 화면 캡처는 포함하지 않습니다.

진단은 자동 업로드하지 않습니다. 사이드바의 진단 보고서에서 미리 보고, 수집을 끄거나 기록을 지울 수 있습니다. 파일 내보내기나 GitHub 이슈 첨부는 사용자가 직접 선택합니다. 공개 이슈에 개인 자료를 붙이지 마세요.

삭제와 보관 기간

워크스페이스·보관 글·웹 세션은 앱 데이터에 남습니다. 사이트 세션은 서비스 자체 정책에 따라 만료됩니다. 사이드바의 개인정보·로그인에서 확인 후 모든 사이트 로그인 정보를 지울 수 있습니다. 앱 데이터 삭제·제거 시 작업과 세션도 사라질 수 있으므로 필요한 자료를 먼저 보관하세요.

소개 페이지와 외부 서비스

이 정적 소개 페이지에는 로그인, 광고, 분석 스크립트 또는 사용자 입력 수집 기능이 없습니다. GitHub Pages의 호스팅 과정에서 GitHub가 접속 정보를 처리할 수 있습니다. 다운로드와 오류 제보를 누르면 GitHub로 이동합니다. 앱 안에서 연 AI 웹사이트는 각 운영사의 정책을 따릅니다.

GitHub 개인정보처리방침 · Plynt 문의

English summary

Workspaces, saved text and normal browser sessions stay on your device. Plynt has no account or synchronization server and does not collect passwords. Selected/copied text is placed in a destination webpage only at your request; that service can access text in its inputs. Diagnostics exclude message content, URLs, credentials and screenshots, and are never automatically uploaded. This static website includes no analytics or login. GitHub and the AI websites you open have their own privacy policies.
